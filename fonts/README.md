# Bundled fonts

| Family | Weights | Licence |
|---|---|---|
| Lato | 300, 400, 700, 900 | SIL Open Font License 1.1 |
| Bebas Neue | 400 | SIL Open Font License 1.1 |
| IBM Plex Mono | 400, 600 | SIL Open Font License 1.1 |

All three are licensed under the SIL OFL 1.1, which permits bundling and
redistribution with an application. Latin and Latin-Extended subsets only, in
woff2 — about 230 KB in total.

They are served from this folder so the board and console render identically
with no internet connection. Nothing here is fetched at runtime.
